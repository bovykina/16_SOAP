# Интеграция веб-сервисами SOAP

## Описание
В учебном проекте изучила принципы взаимодействия информационных систем через протокол SOAP. Разобрала форматы XML, XSD и WSDL, научилась определять структуру сообщений, назначение операций и адреса веб-сервисов. На примере сервисов для управления участниками клуба любителей животных и их питомцами выполнила задания по анализу технической документации и описанию требований к интеграции.

## Полученные навыки
- Понимание SOAP (принципы обмена данными между информационными системами, преимущества и ограничения протокола)
- Чтение XML (структура XML-документов и правила оформления данных)
- Анализ XSD (определение типов данных, обязательности полей, последовательности и количества элементов)
- Анализ WSDL (нахождение операций веб-сервиса, входных и выходных сообщений, а также адреса сервиса)
- Обратное проектирование требований (на основе WSDL описание назначения операций и параметров сообщений, необходимых для взаимодействия систем)

## Этапы проекта
1. Разбор назначения протокола SOAP, формата сообщений XML и особенности интеграции
2. Анализ структуры WSDL, основные части документов и их назначение
3. Изучение операций сервисов
4. Анализ структуры сообщений, изучение типов данных, обязательностей полей, ограничений и форматов входных и выходных сообщений
5. Описание требований к интеграции

## Заключение
Проект помог разобраться в принципах SOAP-интеграции и закрепить навыки анализа технической документации. Полученные знания позволяют системному аналитику описывать взаимодействие информационных систем, понимать структуру передаваемых данных и формулировать требования на основе спецификаций веб-сервисов.
